# BubbleCap

## Wel of geen studiepunten?

Ik zou graag het certificaat willen zonder studiepunten.

## Het project

Voor het project moest ik van school een webshop maken die natuurlijk niet echt gebruikt zou worden door mensen maar wel gewoon zo werkt dat je erdoorheen kan navigeren. Zelf ben ik dit project vroeg begonnen maar heb ik er eigenlijk nooit aan gewerkt tot deze en vorige week omdat ik het steeds druk had met andere dingen. Dat zijn dingen zoals keuzedelen, AVO vakken etc. En ik wist dat ik nog genoeg tijd zou hebben om het af te krijgen voor jaar 1 dus heb ik het best wel vaak opzij gezet.

## Locatie?

Het project is de vinden bij de volgende link: [Website](https://bubblecap.netlify.app/html/index.html)

## Lokaal runnen

Om het project (de website) lokaal te runnen hoef je niet zoveel gekke dingen te installeren. Als je zelf al doet aan coderen heb je misschien al VSCode. Dat is ook wat je hiervoor moet/kan gebruiken. In VSCode moet een een Live Server aanzetten zodat je project altijd up to date is met je code en dan kan word de website automatisch opgestart en nu run je het lokaal.
